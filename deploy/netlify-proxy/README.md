# Relais Netlify

Dossier à déposer sur https://app.netlify.com/drop : Netlify transmet toutes les visites
à `https://clubcine.vercel.app`, pour les réseaux qui bloquent `vercel.app`.

Après le dépôt, renommer le site en `clubcine` (Site configuration, Change site name),
puis mettre `SITE_URL=https://clubcine.netlify.app` dans Vercel pour que les e-mails et les
annonces Discord pointent vers cette adresse.
